# Enhanced Todo List with localStorage and Search
This is a simple Todo List app that lets you add tasks, mark them as completed, delete them, and search through them in real time. All tasks are saved in your browser using localStorage, so they stay even after refreshing the page.

## Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Real-time search filtering
- Persistent storage using localStorage
- Tasks stored as objects: `{id, text, completed}`

## How to Use
1. Type a task in the input field and click **Add Task**.
2. Click on a task to toggle its completion state.
3. Click **Delete** to remove a task.
4. Use the **Search bar** to filter tasks instantly.
5. Page refresh will NOT erase tasks because they are stored in localStorage.

## Files
- `index.html` → UI
- `style.css` → Styles
- `script.js` → Application logic
- `README.md` → Documentation

## Setup
Simply open `index.html` in a browser. No server required.
